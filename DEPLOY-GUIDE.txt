STEP 1 — FREE DATABASE (Neon)  ~4 minutes
───────────────────────────────────────────────
1. Go to  https://neon.tech  → Sign up (use Google login, fastest)

───────────────────────────────────────────────
STEP 2 — FREE APP HOSTING (Render)  ~8 minutes
───────────────────────────────────────────────
1. Go to  https://render.com  → Sign up (Google login again)
2. Click "New +" → "Web Service"
3. Choose "Public Git Repository"?  NO — instead:
   Render needs the code from a Git repo OR you can use their
   "Deploy from GitHub" — simplest path below:

   EASIEST PATH (no Git knowledge needed):
   a. Go to https://github.com → sign up free
   b. Click "+" (top right) → "New repository" → name: buzzflow → Create
   c. On the new repo page click "uploading an existing file"
   d. Drag ALL files from this folder (app.py, requirements.txt,
      Procfile, render.yaml, and the whole static folder*) → Commit
      *GitHub upload keeps folders if you drag the folder itself.
      If it flattens, create the file static/index.html manually via
      "Add file → Create new file", type  static/index.html  as the
      name and paste the content of index.html.
   e. Back on Render: New + → Web Service → "Connect a repository"
      → connect GitHub → pick "buzzflow"
4. Render settings (it may auto-read render.yaml; check these):
   - Name: buzzflow (or anything — becomes your URL)
   - Runtime: Python 3
   - Build command:  pip install -r requirements.txt
   - Start command:  gunicorn -w 2 -b 0.0.0.0:$PORT app:app
   - Instance type:  FREE
5. Scroll to "Environment Variables" → Add:
   Key:   DATABASE_URL
   Value: (paste the Neon connection string from Step 1)
6. Click "Create Web Service" → wait 2–4 minutes for first build
7. DONE! Your permanent link appears at the top:
   https://YOURNAME.onrender.com
